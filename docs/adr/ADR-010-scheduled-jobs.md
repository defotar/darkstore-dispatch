# ADR-010. Периодические задачи

**Статус:** принято

## Контекст

Пересчёт прогноза раз в 20 с и суточные расчёты должна выполнять ровно одна из двух копий.

**Вопрос:** Как выполнить периодическую задачу ровно одной копией

**Основание:** D04-S01-FR023; D03-S02-FR021; D05-S03-FR045; D01-S04-FR010; D04-S01-NFR005

## Варианты

| Вариант | Достоинства | Недостатки |
|---|---|---|
| ShedLock | Блокировка в таблице той же PostgreSQL; при отказе копии задачу берёт другая | После падения копии задача ждёт истечения блокировки |
| Quartz в кластерном режиме | Развитый планировщик | Собственный набор таблиц и планировщик ради нескольких задач |
| Блокировка в Redis | Быстрая блокировка | Появляется Redis, который больше ни для чего не нужен |
| cron на одной ВМ | Простота | При отказе этой ВМ задачи не выполняются |

## Критерии

К1 — при отказе копии задачу выполняет другая; К2 — без отдельного хранилища и набора таблиц планировщика. cron не выполняет К1, Quartz и Redis — К2

## Решение

ShedLock на таблице PostgreSQL.

**Цена решения:** после отказа копии пересчёт пропускает не более одного цикла

## Как проверить

Отключение копии во время пересчёта на стенде
