# ADR-013. Исходящий шлюз

**Статус:** принято

## Контекст

Наружу уходит только запрос к сервису маршрутизации.

**Вопрос:** Как ограничить и журналировать выход в Интернет

**Основание:** D03-S02-FR020; поток F-06; граница Г4

## Варианты

| Вариант | Достоинства | Недостатки |
|---|---|---|
| Squid | Пропуск HTTPS-соединений наружу только к доменам из белого списка, журнал каждого обращения | Ещё одна ВМ в периметре |
| nginx | Уже используется во входном шлюзе | Не пропускает HTTPS-соединения наружу без стороннего модуля |
| Правило межсетевого экрана | Нет отдельного компонента | Нет журнала обращений по доменам |

## Критерии

К1 — пропуск HTTPS-соединения только к разрешённому домену; К2 — журнал каждого обращения. nginx не выполняет К1, межсетевой экран — К2

## Решение

Squid с белым списком из одного домена.

**Цена решения:** ВМ в периметре

## Как проверить

Запрос к постороннему домену отклоняется и попадает в журнал
