# ADR-008. Проверка геозон

**Статус:** принято

## Контекст

При каждой геопозиции проверяется, вошёл ли курьер в геозону даркстора.

**Вопрос:** Как определить прибытие курьера на даркстор

**Основание:** D03-S01-FR019; D01-S04-FR010

## Варианты

| Вариант | Достоинства | Недостатки |
|---|---|---|
| JTS в приложении | Многоугольники нескольких дарксторов лежат в памяти, проверка без обращения к БД | Геозоны перезагружаются в память при обновлении справочника |
| PostGIS | Пространственные запросы в БД | Запрос в БД на каждую точку ради нескольких многоугольников |

## Критерии

К1 — проверка без обращения к БД на каждую точку; К2 — геозоны обновляются вместе со справочником. PostGIS не выполняет К1

## Решение

Библиотека JTS в ФП-3.

**Цена решения:** перезагрузка геозон при изменении справочника

## Как проверить

Тест на эталонных точках внутри, вне и на границе геозоны
