# ADR-014. Развёртывание

**Статус:** принято

## Контекст

Одно приложение работает в двух одинаковых копиях.

**Вопрос:** Как развернуть приложение кластера

**Основание:** Архитектура (docs/04); D04-S01-NFR005

## Варианты

| Вариант | Достоинства | Недостатки |
|---|---|---|
| Docker на двух ВМ | Одинаковый образ в обеих копиях и во всех средах, без отдельного слоя управления | Обновление выполняется по очереди скриптом |
| Kubernetes | Автоматическое восстановление и обновление | Управляющий кластер ради одного приложения |
| Запуск без контейнеров | Минимум слоёв | Окружения копий со временем расходятся |

## Критерии

К1 — одинаковое окружение обеих копий и сред; К2 — без отдельного слоя управления ради одного приложения. Запуск без контейнеров не выполняет К1, Kubernetes — К2

## Решение

Docker на двух ВМ прикладного сегмента.

**Цена решения:** обновление копий по очереди скриптом

## Как проверить

Обновление копий по очереди без остановки выдачи направлений
