# Архитектурные решения (ADR)

Каждое решение: вопрос → критерии → варианты → выбор и его цена → как проверить. Критерии подобраны так, чтобы для каждого отвергнутого варианта был назван критерий, который он не выполняет, или показано, что его преимущество проекту не нужно.

| ADR | Вопрос | Решение |
|---|---|---|
| [ADR-001](ADR-001-api-contract.md) | Контракт API для внешних интерфейсов | REST/JSON с отдельным контрактом OpenAPI на каждую интеграцию |
| [ADR-002](ADR-002-direction-delivery.md) | Доставка направления курьеру | Направление возвращается синхронным ответом на отметку, смена в пути отправляется уведомлением серверу приложения курьера |
| [ADR-003](ADR-003-platform.md) | Серверная платформа модульного монолита | Java 21, Spring Boot 3, Spring Modulith; модуль соответствует ФП или ОФ |
| [ADR-004](ADR-004-aggregate-persistence.md) | Доступ к данным агрегатов | Spring Data JDBC |
| [ADR-005](ADR-005-operational-db.md) | Оперативная база данных | PostgreSQL 16; схемы d01–d05 с отдельными учётными записями модулей; журнал решений в схеме d05 с помесячными разделами |
| [ADR-006](ADR-006-db-failover.md) | Резервирование базы данных | Patroni на двух ВМ базы данных, etcd на трёх узлах |
| [ADR-007](ADR-007-track-storage.md) | Хранение трека геопозиций | Отдельная база PostgreSQL 16 на своей ВМ, суточные разделы, ночное удаление раздела старше 30 дней |
| [ADR-008](ADR-008-geofences.md) | Проверка геозон | Библиотека JTS в ФП-3 |
| [ADR-009](ADR-009-event-broker.md) | Доставка событий смежных систем | RabbitMQ на трёх узлах с кворумными очередями. В АС исходящие события сохраняются в реестре Spring Modulith в транзакции изменения данных, входящие сверяются с таблицей обработанных идентификаторов |
| [ADR-010](ADR-010-scheduled-jobs.md) | Периодические задачи | ShedLock на таблице PostgreSQL |
| [ADR-011](ADR-011-ingress-gateway.md) | Входной шлюз | nginx на двух ВМ с общим адресом через keepalived |
| [ADR-012](ADR-012-darkstore-permissions.md) | Права по даркстору | Токены сервера учётных записей сети, проверка в ОФ-2 средствами Spring Security; системы дополнительно предъявляют сертификат |
| [ADR-013](ADR-013-egress-gateway.md) | Исходящий шлюз | Squid с белым списком из одного домена |
| [ADR-014](ADR-014-deployment.md) | Развёртывание | Docker на двух ВМ прикладного сегмента |
| [ADR-015](ADR-015-observability.md) | Наблюдаемость | Micrometer в приложении, агент Grafana Alloy на ВМ, Prometheus, Loki и Grafana в зоне контроля; координаты в журналы не записываются |
| [ADR-016](ADR-016-analytics-mart.md) | Витрина данных для аналитики | Отдельная база PostgreSQL 16, логическая репликация, ELT по ночам |
| [ADR-017](ADR-017-cache.md) | Кэш ответов внешних систем | Caffeine внутри приложения |
